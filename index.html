    CodeFlow JSON format

    Use a CodeFlow export whenever possible. Imports must be UTF-8 JSON, at most 2 MB, with schemaVersion: 2. Valid version 1 exports are migrated without changing the source file.

    This is the smallest valid empty project:

    {
  "schemaVersion": 2,
  "id": "example-project",
  "name": "Example architecture",
  "rootBoardId": "board-root",
  "boards": {
    "board-root": {
      "id": "board-root",
      "name": "System architecture",
      "ownerBlockId": null,
      "blocks": [], "edges": [], "zones": [],
      "viewport": { "x": 0, "y": 0, "zoom": 1 }
    }
  }
}

    For diagrams, each board may contain blocks with unique IDs, labels, levels, positions and named input/output ports. Edges reference valid source and destination port IDs; child boards point back to their owning block. Edge annotations may include caption, dataType, format, description and schemaRef. Saved layouts and tours are optional.
